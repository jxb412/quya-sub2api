# Quya Sub2API

これは `jxb412/quya-sub2api` が保守する Sub2API 個人版です。AI API ゲートウェイ、
アカウント管理、API キー認証、課金、ルーティング、フェイルオーバー、同時実行数
制御と管理画面を提供します。

詳細な仕様、注意事項、更新方法、デプロイ手順は中国語版を参照してください。

- [README_CN.md](README_CN.md)
- [Deployment guide](deploy/README.md)
- [Project handoff](docs/PROJECT_HANDOFF_CN.md)

本番環境では、データベースのバックアップ、永続ボリュームの確認、上流サービスの
利用規約と適用法令の確認を行ってください。初回セットアップと起動時データベース
初期化はデフォルトで無効です。
